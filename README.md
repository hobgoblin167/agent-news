**Новостной ИИ-агент, который суммирует последние новости , написанный на Python.**

использованные технологии : Python, llama-cpp, LangGraph, Sqlite, requests

Обзор:

**ветка main** - тут скорее для исследования структуры, посмотреть как работает приложение.
Вкратце: подключаемся к локальной LLM на сервере (я использую Qwen3.5-9B-Q4_K_M) 
Агент отправляет запрос на BBC NEWS, смотрит новости, есть ли что-то актуальное, сверяет с базой данных
Если есть новые статьи, записывает их в Базу Данных и проводит суммаризацию. Выводит результат в приложение.

**ветка gui** - доработанное приложение с красивым интерфейсом и streaming режимом. Рекомендую использовать эту версию для ежедневного пользования.
